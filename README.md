# Erzsébet-telepi Polgárőr Egyesület – Desktop

Electron alapú asztali alkalmazás a jelenlegi Erzsébet-telepi Polgárőr Egyesület rendszeréhez.

## Első verzió

Az alkalmazás a meglévő webes rendszert tölti be saját macOS/Windows alkalmazásablakban. Az adatbázis és a VPS-en futó rendszer változatlan marad.

Webes rendszer: https://www.bp18polgarorseg.hu/app.html

## Fejlesztés

npm install
npm start

## Build

npm run build:mac
npm run build:win

Az első kiadás szándékosan nincs kódaláírással ellátva, hogy az induló verzió 0 Ft-os maradjon.

## Következő fejlesztések

- saját alkalmazásikon
- indító / betöltőképernyő
- stabil frissítési rendszer
- macOS és Windows kiadások
- később opcionális kódaláírás és hitelesített terjesztés
